Importar Guías de Despacho

Sube el archivo "Query Guías de Despacho" (.xlsx) — el mismo que usas en Control de Negocios. Se procesan solo las guías Tipo = S (Salida) y Estado = V (Vigente); el resto se descarta. Solo se cargan las guías de los últimos 7 meses. Guarda N° de Guía, N° de NV, N° de Factura, cliente, vendedor, patente, quién retiró y el detalle de códigos despachados.

Importar Clientes

Sube el archivo "Query Clientes Vista" (.xlsx). Se usa para completar Dirección, Comuna, Ciudad, Giro, Teléfono y R.U.T. en el formato de Consulta Guías — solo se guardan esos datos, nada del resto del archivo (claves, preguntas secretas, cupos de crédito, etc. se descartan).

Importar Histórico

Carga solicitudes de postventa anteriores a esta app, para tener datos con los que alimentar el Historial y el Dashboard. No borra ni reemplaza nada de lo que ya existe — cada carga se suma a lo actual.

Sincronización entre equipos

Los datos se guardan en Firebase (Firestore) — todos los usuarios ven lo mismo automáticamente, no requiere configuración por equipo.

Migración desde jsonbin (una sola vez)

Trae lo que ya estaba guardado en el sistema anterior y lo sube a Firestore. Solo hace falta hacerlo una vez — después de confirmar que todo llegó bien, este panel se puede ignorar.
